# BusLiner // Экосистема междугородней мобильности

Единая цифровая платформа для пассажиров, частных перевозчиков и автопарков междугородних микроавтобусов: 100% онлайн-продажи, алгоритмический автоперехват отказных мест («Снайпер»), мобильный пульт водителя со сканером QR-кодов по камере и ежедневные выплаты на расчетный счет (IBAN).

---

## Архитектура и ключевые модули

Платформа BusLiner построена как распределенная клиентская веб-экосистема без тяжелых серверных зависимостей, работающая автономно в любом современном браузере. Модули синхронизируются в реальном времени через `BroadcastChannel` API и реактивное хранилище `localStorage`.

### 1. Главная презентация для пассажиров (index.html)
* **Дек-презентация первого класса**: 6 полноэкранных кинетических слайдов (Обложка, Манифест, Салон, Флот, Снайпер, Контакты) с видео-фоном высокого разрешения (`assets/video/hero-city.mp4`) и пленочной цветокоррекцией.
* **Dual Engine (Desktop + Mobile)**:
  * *Desktop*: перелистывание колесом мыши с защитой от двойного скролла (`wheel debounce` 480 мс), боковой рельс пагинации (`presentation-side-rail`), клавиатурная навигация и кастомный лерп-курсор.
  * *Mobile*: свободный инерционный скролл 120 Гц, мягкий секционный доводчик (`scroll-snap-type: y proximity`), плавающий нижний пульт (`mobile-deck-dock`) с шагом `01 / 06` и тактильными кнопками переключения, поддержка горизонтальных свайпов.
* **Поисковый монолит**: подбор рейсов по маршрутам Минск, Гродно, Вильнюс, Брест, Гомель с интерактивным календарем.

### 2. Платформа для перевозчиков и автопарков (busliner-partners.html)
* **Презентационный стейдж для B2B**: идентичная дек-архитектура в стилистике Quiet Luxury (Loro Piana / Bottega Veneta / Apple Craft).
* **Интерактивный финансовый калькулятор**: расчет чистой прибыли автопарка в реальном времени в зависимости от числа машин (1–15), рейсов в день (1–6) и тарифа. Сравнение с традиционными кассами вокзалов (ликвидация No-Show, комиссия экосистемы 5%, чистая выплата на IBAN).
* **Симулятор бота-снайпера**: наглядная демонстрация алгоритмического выкупа отказных билетов за 0.38 секунды с зачислением средств на эскроу-счет рейса.
* **Проверенные отзывы перевозчиков и форма экспресс-подключения**: интеграция автопарка за 24 часа.

### 3. Кабинет перевозчика и пульт водителя (carrier-workspace.html, carrier-dashboard.html)
* **Аналитика парка и статистика для перевозчика (Режим перевозчика)**:
  * **Сводная бизнес-аналитика**: валовая выручка парка (Gross), чистые выплаты на р/с (Net Settlement после комиссии 5%), процент загрузки кресел и индекс надежности/пунктуальности флота.
  * **Интерактивный векторный график 7-дневной динамики**: визуализация суточной выручки и процента заполняемости на чистом SVG без внешних библиотек с выделением лучшего дня недели.
  * **Маржинальность и доходность регулярных линий**: детальный анализ направлений (Минск — Вильнюс, Минск — Варшава, Минск — Гродно, Брест) с индикацией среднего чека и доходности на 1 км пробега.
  * **Телеметрия и мониторинг бортов автопарка**: суточный пробег, статус активности («На линии», «На базе / Резерв»), закрепленные экипажи и межсервисные интервалы ТО для каждого микроавтобуса.
  * **Рейтинг и дисциплина водителей**: статистика выполненных рейсов, пассажирские оценки (4.98/5.0), точность сканирования QR-билетов и безаварийность.
  * **Финансы и автоклиринг на IBAN**: реестр рейсов, расчет 5% сервисного сбора платформы, формирование электронных актов и реквизиты белорусского счета в формате IBAN.
* **Тактический пульт рейса (Режим водителя)**:
  * Быстрое переключение одной кнопкой в верхней панели и боковом меню.
  * **Камера-сканер QR-кодов в реальном времени**: встроенный сканер с доступом к видеокамере смартфона (`navigator.mediaDevices.getUserMedia`), двойной декодер (`BarcodeDetector` + `jsqr.min.js`), фонарик, переключение камер и большая эргономичная кнопка (60px).
  * **Интерактивная 3D-схема микроавтобуса (Sprinter 20 мест)**: наглядный салон с цветовой индикацией занятых, свободных и подтвержденных на посадке мест.
  * **Официальный посадочный реестр (СТБ 1389)**: список пассажиров, фильтрация по статусу билета, звонок пассажиру в 1 тап (`tel:`), отметка «В салоне • Билет принят».

### 4. Личный кабинет пассажира (passenger-cabinet.html)
* **UX в традициях лучших тревел-сервисов**: удобное переключение табов (Мои билеты, Консьерж-Снайпер, Поиск рейсов, Профиль).
* **VIP AI Консьерж-Снайпер**:
  * Алгоритм автоматического мониторинга и выкупа отказных билетов при полном солдауте рейса.
  * Радар с циклом сканирования 300 мс.
  * Автоматический перехват за 0.38 секунды и моментальное оформление билета на паспортные данные клиента.
  * Интерактивная симуляция перехвата для тестирования.
* **Электронный посадочный талон**: векторный QR-код билета, время до отправления, номер забронированного кресла, скачивание в Apple Wallet и PDF.

## Технологический стек

* **Среда выполнения**: Vanilla JavaScript (ES6+), HTML5, CSS3 Custom Properties.
* **Типографика**: Cormorant Garamond (Editorial Serif), Plus Jakarta Sans (Humanist Grotesk), JetBrains Mono (Telemetry Monospace).
* **Цветовая палитра Quiet Luxury**:
  * Warm Ivory (`#F5F1EA`), Bone (`#E8E2D6`), Sand (`#D9CDB8`)
  * Alpine Forest (`#23312A`), Oxblood (`#5C2E2E`), Graphite (`#2B2A28`)
  * Полное исключение чистого белого `#FFFFFF` и чистого черного `#000000`.
* **Обработка QR-кодов**: нативный `BarcodeDetector` + встроенный `assets/jsqr.min.js` (без сетевых запросов и внешних CDN).
* **Синхронизация между вкладками**: `BroadcastChannel('busliner_channel')` + `storage` event listener.
* **Звуковой движок**: Web Audio API (генерация полифонических частотных сигналов подтверждения посадки и выкупа без внешних audio-файлов).

## Стандарты эргономики и чистоты кода

1. **Строго 0 эмодзи и смайликов**: все статусы, маркеры и указатели оформлены через типографику и векторные SVG-иконки.
2. **Строго 0 тегов `<img>`**: графика и схемы салонов отрисованы на чистом векторном inline-SVG и CSS.
3. **Строго 0 квадратных скобок в видимом UI**: исключены технические маркеры вида `[...]` в пользовательском интерфейсе.
4. **Тач-таргеты и поля ввода**: все кликабельные элементы $\ge 48$px, шрифты полей ввода $\ge 16$px (защита от принудительного зума iOS Safari).
5. **Mobile-Native**: плавающий адаптивный док на смартфонах, инерционная прокрутка 120 Гц, поддержка безопасных зон `env(safe-area-inset-*)`.

## Запуск и тестирование

### Локальный запуск
Для работы сканера камеры и кросс-доменных политик рекомендуется локальный HTTP-сервер:
```bash
cd BusLiner
python3 -m http.server 8080
```
После запуска откройте в браузере:
* Главная страница для пассажиров: `http://127.0.0.1:8080/index.html`
* Презентация для автопарков: `http://127.0.0.1:8080/busliner-partners.html`
* Кабинет пассажира (Снайпер и билеты): `http://127.0.0.1:8080/passenger-cabinet.html`
* Рабочий пульт водителя со сканером: `http://127.0.0.1:8080/carrier-workspace.html`

### Запуск полного набора тестов E2E
```bash
python3 tests/run_all_e2e_tests.py
```
Результат: **194/194 тестов пройдены успешно (100.0%)**.
